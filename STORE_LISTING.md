Copy these into the Chrome Web Store and Microsoft Edge Add-ons submission forms.

## Name
Playlist Total Duration for YouTube

## Short description / summary (max 132 characters)
Shows the total length of the current YouTube playlist next to the position counter, e.g. "1 / 5 4:25:14".

## Detailed description
Ever wondered how long a playlist will take to watch? This extension adds the total
duration of the current playlist right after the position counter in the playlist panel
on YouTube watch pages.

Example: 1 / 5 4:25:14

Features
- Sums the duration of every video in the playlist panel
- Updates automatically when you switch videos or playlists
- Lightweight: no settings, no permissions, no tracking

Privacy
This extension collects no data, makes no network requests, and stores nothing. It only
reads the durations already shown on the page.

This extension is not affiliated with or endorsed by YouTube or Google.
