# Privacy Policy — Playlist Total Duration for YouTube

_Last updated: 2026-10-25_

This extension does not collect, store, transmit, or sell any personal data.

- It runs only on `https://www.youtube.com/*` pages.
- It reads the video durations shown in the playlist panel on the current page, adds them
  up in your browser, and displays the total next to the playlist position counter.
- It makes no network requests, uses no analytics or tracking, and stores nothing
  (no cookies, no local storage, no sync storage).
- It requests no extension permissions beyond running its content script on youtube.com.

If you have questions, open an issue in this project's GitHub repository.
